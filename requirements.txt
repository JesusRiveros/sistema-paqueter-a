# Instalacion y ejecucion local
# Requiere Python 3.10 o superior.
#
# 1. Desde la raiz del repositorio, crea y activa un entorno virtual:
#      Windows (PowerShell):  py -m venv .venv ; .venv\Scripts\Activate.ps1
#      Linux/macOS:           python3 -m venv .venv && source .venv/bin/activate
# 2. Instala dependencias:    python -m pip install -r requirements.txt
# 3. Copia .env.example como .env y completa SECRET_KEY y GOOGLE_MAPS_API_KEY.
#    (El proyecto de Google Cloud debe tener la facturacion activada.)
# 4. Inicia la aplicacion:
#      cd "sistema paqueteria"
#      python app.py
#    Sitio: http://127.0.0.1:5001/   Cotizador: http://127.0.0.1:5001/app/
#
# Pruebas:   cd "sistema paqueteria" ; python -m pytest -q tests
#
# Actualizar el rastreo de un envio (estados: creado, recolectado, en_transito,
# en_reparto, entregado):
#   cd "sistema paqueteria"
#   flask --app app avanzar-envio BLL-XXXXXXXX en_transito --ubicacion "CEDIS Vallejo, CDMX"
